Request lifecycle

There is no HTTP request. A "request" is a user gesture that travels through React → the store → pure rules → persistence → re-render, entirely in the browser.

Why the two-step split (2 then 3)?

  • Side-effects before setState, state inside it. React StrictMode double-invokes updaters in dev; firing sound inside would double-play and could double-count combos.
  • The store picks the sound because only it knows the full before/after (level vs. rank, mission, weekly, combo) — a component can't. See ADR-0005.
  • XP is never stored — step 4 recomputes it from tasks. See ADR-0002.
