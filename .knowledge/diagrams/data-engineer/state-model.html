State model

The whole "database" is one JSON object under localStorage['garage-reset-v1']. Blue = persisted state · green = reference data (in code) · orange = derived (never stored).

Second key

  • localStorage['arcade-muted'] — "0"/"1", owned entirely by sound.ts.

What this means for a backend

  • Small sync surface. Only tasks, items, and the scalar counters are authoritative — the derived layer never needs to sync.
  • No identity. The blob has no user/device id and no version — the first thing to add for multiplayer.
  • Single writer. One effect in store.tsx is the only writer, so the seam is singular. See readiness overview.
