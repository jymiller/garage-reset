About

What it is

A single-page React 19 app. Three players (John, Griffin, LJ) clear cleanup quests; finishing them earns weighted XP that drives an arcade progression system and a friendly leaderboard. A separate 3D view models the physical garage. Everything runs in the browser — there is no server and no database.

Why this knowledge base

To let a newcomer (or an AI agent) understand the whole app fast, and to map its readiness for the likely next chapter: moving from single-device localStorage to a shared, real-time backend/multiplayer future. Markdown is the source of truth; these HTML pages are the visual layer.

Design constraints & how to maintain this KB
  • MD is source of truth. Edit the .md files; these HTML pages are derived, hand-built views.
  • Self-contained HTML. All CSS/SVG is inline — no CDNs, works offline via file:// or the server.
  • Relative links only, so navigation works both from disk and the dev server.
  • Progressive disclosure: 30,000 ft (overview) → 5,000 ft (domains) → ground level (file cards).
  • Read the app's own docs too: DESIGN.md, ROADMAP.md, ASSETS.md.

One store, pure rules, dumb views
